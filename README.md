# פשוטלפון
> **פשוט טלפון ורק טלפון**

אתר סטטי בעברית מלאה ובכיווניות RTL, שנועד לעזור למבקרים להכיר טלפונים פשוטים ולבחור מכשיר שמתאים לצרכים שלהם — לאנשים שמחפשים מכשיר מקשים פשוט עם מעט אפליקציות והסחות דעת.

האתר נבנה ומתופעל על ידי חובב התחום בהתנדבות מלאה ואין שום אחריות על המידע בו ישירה או עקיפה.

## מטרת האתר ועקרונות מרכזיים
- **טלפוני מקשים בלבד:** כל המכשירים המוצגים באתר הם מכשירים בעלי מקלדת מקשים פיזית. חלקם משלבים בנוסף גם מסך מגע.
- **דף "רשימת המומלצים שלנו" (`recommended.html`):** דף ייעודי נפרד המציג רק מכשירים שעומדים ב-5 קריטריונים מחמירים (מקשים בלבד, ללא וידאו ורדיו, ללא אינטרנט/אפליקציות, ללא גרסה שונה - נקי לחלוטין, וכולל SMS).
- **תמיכה בכרטיס זיכרון:** הצגת תמיכה והרחבת זיכרון בכרטיסי המכשירים ובשאלון ההתאמה.
- **מסך אבחון מרוכז בשאלון:** בעת אי-התאמה לתנאי חובה, המערכת מציגה ניתוח מרוכז של התנאים שהכשילו, זיהוי סתירות מובנות והמלצות לפתרון במקום פירוט חוזר לכל מכשיר בנפרד.
- **מדריך מושגים במבנה אחיד:** 4 מושגים טכניים בלבד המוצגים בשורה אחת במחשב.
- **שקיפות והתנדבות:** האתר אינו חנות מסחרית, אינו מוכר מכשירים ואינו מקבל תשלומים. האתר נבנה ומתופעל על ידי חובב התחום בהתנדבות מלאה, ואין שום אחריות על המידע בו ישירה או עקיפה. ליצירת קשר: `info@pashutphone.example.com`.

## רמות נקיות המוגדרות באתר
 באתר מוגדרות 3 רמות נקיות מדויקות:
1. **נקי לחלוטין:** המכשיר נמכר אך ורק עם הפונקציות שכתוב שיש בו באתר. אין עבורו גרסה פתוחה או אפשרות להוספת יישומים.
2. **נקי:** ניתן להשיג מכשיר התואם את מה שכתוב באתר, אך קיימות בשוק גם גרסאות פתוחות יותר. בכרטיס המכשיר מופיעה הרחבה המפרטת את ההבדל.
3. **מנוקה (רלוונטי לסמארטפונים מצומצמים):** ניתן להשיג מכשיר מסונן ברמות כאלו ואחרות (תלוי בחנות/ספק), אך ניתן להשיג גם מכשיר פתוח לחלוטין כמו סמארטפון רגיל.

## הרצה מקומית

### אפשרות א': פתיחה ישירה בדפדפן (ללא שום שרת)
לחצו פעמיים על הקובץ `index.html` בכל דפדפן (Chrome, Firefox, Edge, Safari). המערכת תיטען מיידית.

### אפשרות ב': שרת פיתוח מקומי קל
באמצעות פייתון (ללא התקנות נוספות):
```bash
python3 -m http.server 8000
```
וצפייה בכתובת `http://localhost:8000`.

## הוספת מכשיר חדש (קובץ Markdown)
צרו קובץ `.md` חדש בתיקיית `data/phones/`.

דוגמה לקובץ:
```markdown
---
id: "my-phone"
manufacturer: "שם היצרן"
model: "שם הדגם"
phone_type: "טלפון טיפש" # אפשרויות: טלפון טיפש | פיצ'ר פון | סמארטפון מצומצם
has_touch_screen: false # האם כולל מסך מגע בנוסף למקשים: true / false
clean_level: "נקי לחלוטין" # אפשרויות: נקי לחלוטין | נקי | מנוקה
clean_level_details: "פירוט על רמת הנקיות ועל גרסאות פתוחות אם קיימות"
operating_system: "מערכת ייעודית"
message_storage: "עד 500 הודעות SMS"
features:
  - "מקלדת מקשים פיזית"
  - "פנס מובנה"
  - "סוללה ארוכת טווח"
price:
  min: 150
  max: 200
  currency: "₪"
  certainty: "טווח משוער" # מדווח | טווח משוער | מידע שלא אומת | לא ידוע
  source: "זאפ השוואת מחירים"
  checked_date: "2026-10-01"
purchase_links: []
image: "assets/images/phones/my-phone.png"
image_alt: "תמונת המכשיר"
is_sample: false
---

# תיאור הדגם
כאן ניתן לכתוב בפורמט Markdown חופשי תיאור של המכשיר ויתרונותיו.
```

## הוספת תמונות ועדכון נתונים
1. הניחו את קובץ התמונה בתיקייה `assets/images/phones/`.
2. עדכנו את השדה `image` בקובץ ה-Markdown של המכשיר.
3. הוסיפו תיאור נגיש בשדה `image_alt`.

## מדריך המושגים הטכניים (4 מושגים מובנים)
המדריך מכיל בדיוק 4 מושגים טכניים המוצגים בשורה אחת אחידה:
1. **סוג המכשיר (`#phone-type`):**
   - **טלפון טיפש:** ללא דפדפן, ללא אפליקציות אינטרנט וללא שום אופציה להתקנת יישומים. יכול לכלול מוזיקה, מצלמה, רדיו ופנס.
   - **פיצ'ר פון:** מכשיר מקשים המבוסס על מערכות ייעודיות עשירות יותר (KaiOS, גרסאות של Mocor וכו').
   - **סמארטפון מצומצם:** מכשיר מקשים (המשלב לעיתים מסך מגע) המאפשר כלים מעשיים ספורים ללא רשתות חברתיות ופידים ממכרים.
2. **רמת נקיות (`#clean-level`):** נקי לחלוטין (רק מה שרשום באתר), נקי (קיימת גם גרסה פתוחה יותר), מנוקה (סמארטפון שניתן להשיגו מסונן או פתוח לחלוטין).
3. **מערכת הפעלה (`#operating-system`):**
   - מערכת ייעודית בסיסית: **RTOS, Mocor**.
   - מערכת פיצ'ר פון: **KaiOS, גרסאות מסוימות של Mocor, וגרסאות מסוימות של אנדרואיד**.
   - אנדרואיד מצומצם: גרסה מינימליסטית ללא חנויות אפליקציות וללא שירותי תוכן ממכרים.
4. **אחסון הודעות (`#message-storage`):** קיבולת שמירת הודעות SMS בזיכרון המכשיר.

עוגני העזרה בכרטיסי המכשירים מפנים ישירות למושג המתאים ומדגישים אותו בהבזק חזותי.

## עדכון קובצי הנתונים (סקריפט Build)
לאחר הוספת או עריכת קובצי Markdown, הריצו:
```bash
python3 scripts/build_data.py
```
הסקריפט יאמת את הקבצים ויעדכן את `data/phones.json`, `data/glossary.json` ו-`assets/js/sample-data.js`.

## פרסום ב-GitHub Pages
1. בצעו push למאגר ה-GitHub שלכם.
2. בהגדרות המאגר (Settings) > בחרו **Pages**.
3. מקור: `Deploy from a branch`, ענף `main` ותיקיית `/ (root)`.
4. שמרו. האתר יהיה זמין בכתובת: `https://<username>.github.io/<repo-name>/`.
5. כל הקישורים והנתיבים הם יחסיים, כך שהאתר עובד מיד בכל תת-תיקייה.
